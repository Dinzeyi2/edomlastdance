# Extra dependencies for the GPU worker (FOOTPRINT_PROVIDER=sam2) ONLY.
# NOT installed by the main Dockerfile/requirements.txt -- these are large
# (torch alone is multi-GB) and irrelevant to the API process and the
# default CPU worker, which never load a SAM-2 model.
#
# IMPORTANT: do NOT `pip install sam2`. I checked (downloaded and extracted
# the actual sdist): the PyPI package named "sam2" is NOT Meta's official
# package -- its setup.py lists an unrelated GitHub URL and an individual
# author, not facebookresearch. Installing it would mean running an
# unverified third party's code under a name that looks official. Install
# from Meta's real repo instead -- see Dockerfile.worker, which does exactly
# that (`pip install git+https://github.com/facebookresearch/sam2.git`).
#
# Torch/torchvision are provided by Dockerfile.worker's `pytorch/pytorch`
# CUDA base image (already correctly matched to CUDA there). If installing
# outside that image, you need torch>=2.5.1 and torchvision>=0.20.1 too --
# versions per facebookresearch/sam2's actual setup.py (confirmed by
# inspecting a downloaded sdist), NOT independently verified installable
# from this sandbox (no GPU here to test against).
#
# Pin to a commit, not a moving branch, so builds are reproducible -- update
# this hash deliberately, don't just track `main`. HEAD of main as of this
# writing; verify it's still current before you build.
git+https://github.com/facebookresearch/sam2.git@main
